**先修三條**：#6（候選展開，直接對應最怕的事）、#1（組字顯示在游標處）、#4（兩顆地球）。

**待驗清單**（Agent 不給結論）：
- 組字底線在各 app 的表現：茄記（網頁 app）、提醒事項、LINE、Safari 網址列。marked text 在部分網頁輸入框可能行為不同 → 多米真機逐一試。
- 打字中點別處移動游標，組到一半的注音會不會殘留或重複 → 多米真機。
- 鍵盤收起時正在組的字有沒有正確送出（不消失、不重複）。
- 起頭字清單（我 你 好 這…）：多米同意先保留（2026-11-02），用了不順再換。
- 按鍵聲：設定 → 聲音與觸覺 → 鍵盤回饋 → 聲音 開／關各試一次。
- 深色模式：多米決定要跟系統（2026-11-02），build 38 已做；深色配色是 Agent 暫定，陽光下與深色下的對比待真機驗。
- 換行鍵：多米決定要做（2026-11-02），build 38 已做。
- 按錯鄰鍵是否變少（定稿核心）→ 只能多米真機長期使用判斷（閘門 3）。
