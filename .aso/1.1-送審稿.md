## 一、新功能說明（What's New）

只多最後一條，前四條跟後台現在的一樣。後台可以整欄貼掉，也可以交給 asc-metadata 工作流程寫（見第四節）。

### 繁體中文

```
- 空白鍵可以當一聲：沒打聲調就按空白，候選只剩一聲的字。不習慣的話，設定頁可以改回直接選字
- 字典可以用 iCloud 同步，也能匯出成檔案備份。預設是關的，到設定頁打開
- 換了新的外觀和圖示，App 底下改成四個分頁：字典、剪貼簿、主題、設定。使用說明搬進設定頁
- 英文鍵盤拿掉上面那排工具列，鍵變大了
- 英文不會再自動大寫，要大寫自己按 ⇧。之前在空的輸入框裡，⇧ 會一直亮著、按了也關不掉，這版修好了
```

### 英文（英國）

```
- The space bar can enter the first tone: skip the tone, press space, and only first-tone characters are left. You can switch back in Settings
- Your dictionary can sync with iCloud or be exported as a file. Sync is off by default; turn it on in Settings
- A new look and icon. The app now has four tabs: Dictionary, Clipboard, Themes and Settings. The guide has moved into Settings
- The English keyboard no longer has the toolbar on top, so the keys are bigger
- English no longer capitalises on its own; tap ⇧ when you want a capital. In an empty text field, ⇧ used to stay on and wouldn't turn off. That's fixed
```

App 內的新功能卡片第三點也同步加了「也不會再自動大寫」，兩邊講同一件事。

## 二、App 審查資訊的備註（英文，接在原本備註後面）

1.0 的備註（怎麼加鍵盤、Full Access is optional、主題在哪買）原樣留著，最後面補這段，讓審查員知道 1.1 多了什麼、在哪裡看得到：

```
What's new in 1.1 for review:
- iCloud sync for the user dictionary (Settings > Data). It is off by default and uses the user's own iCloud key-value store. The keyboard extension still has no network code; only the app syncs.
- Dictionary export/import as a file (Settings > Data).
- A first-launch setup screen that shows how to add the keyboard. Tap "略過" (top right) to skip it.
- Bug fix: the English layout no longer auto-capitalises. Shift used to stay on in an empty text field and could not be turned off.
Full Access is still optional. Without it, typing works normally; only word learning, the clipboard panel and paid themes need it.
```

## 三、要不要申請加速審核（Expedited Review）

我覺得可以申請，但別指望一定過。Apple 收加速的條件是「緊急修 bug」，1.1 同時帶了新功能（iCloud、新外觀），審查員可能照一般排隊。申請不會有壞處，被拒就是照常 1～3 天。

送審後到 [developer.apple.com/contact/app-store](https://developer.apple.com/contact/app-store/?topic=expedite) 填「Request an expedited app review」，說明欄貼：

```
Version 1.1 fixes a keyboard bug in the current release (1.0): in an empty text field, the Shift key on the English layout stays on and cannot be turned off, so users cannot type lowercase English at the start of a message (for example in LINE). This version removes the auto-capitalisation that caused it. We would be grateful for an expedited review.
```
