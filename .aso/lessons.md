# lessons

- 2026-11-14｜domi-aso-copy｜1.0 描述原稿裡的注音符號（「ㄢ 打成 ㄦ」「介音 ㄧㄨㄩ」）上架後在頁面上不見了｜下次規則：描述、推廣文字、新功能說明不放注音符號和聲調符號，用 `check_copy.py` 擋；要秀注音放在截圖裡。
- 2026-11-14｜domi-aso-copy｜1.1 加了 iCloud 同步，頁面上還寫「豆鍵沒有任何連網功能」｜下次規則：每次改版先列出這版新增的連網、權限、資料去向，對一次描述的隱私段和隱私權政策（承諾會倒過來約束產品，反過來也一樣）。
- 2026-11-14｜domi-aso-control｜1.0 的關鍵字欄位沒實搜就寫，放了「ㄅㄆㄇ」，實搜前十名全是兒童學注音｜下次規則：「注音」單獨一個字、「ㄅㄆㄇ」在台灣店面是學注音的意圖，鍵盤類不放。
- 2026-11-14｜domi-aso-control｜名稱有「注音鍵盤」四個字，搜「注音鍵盤」還是排不進前 12，前面的對手評分數只有個位數到幾十｜下次規則：字齊了排不上，先查是不是缺下載和評分，不要急著改名稱。
- 2026-11-14｜domi-aso-copy｜1.1 把英文鍵面的工具列拿掉，英文建議字跟著沒了｜下次規則：寫新功能說明前讀 `App/Veggie/WhatsNew.swift` 和這版的 git log，不要照產品定稿寫（定稿會落後於實作）。
- 2026-11-17｜送審｜1.2.1 新功能說明寫了「登入頁的 email 欄現在叫得出豆鍵」，根據只有多米一句「功能都 ok」；送出後多米才說那一欄只有原生鍵盤能用，只好撤回重送｜下次規則：新功能說明裡每一條「修好了」都要有真機逐項的回報才寫，籠統的「都 ok」不算；模擬器重現不了的問題尤其要先問那一項的結果再寫。撤回重送用 `asc_release.py --withdraw --submit <build 號>`。
- 2026-11-25｜競品｜矩陣「空位」四條，十一天內兩條（不換排法、空白鍵當一聲）被新 app 佔走、一條變弱；其中兩條是用「沒有對手有」的說法寫的｜下次規則：空位每次送審前重查一次（公開查詢 API 幾分鐘就查完），「沒有對手有」只留在內部文件，不寫進商店文案。
