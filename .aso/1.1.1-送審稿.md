# 豆鍵 1.1.1 送審稿（英文 ⇧ 緊急修復）

> 2026-11-16 寫。線上的 1.1（1.0 也一樣）有個 bug：在空的輸入框切到英文，⇧ 一直亮著，按了也關不掉。
> 1.1.1 只修這個，順便拿掉英文的自動大寫：要大寫自己按 ⇧。其他功能、文案、截圖都跟 1.1 一樣。

---

## 一、新功能說明（What's New）

### 繁體中文

```
修正英文鍵盤的大寫問題：之前在空的輸入框裡，⇧ 會一直亮著、按了也關不掉。現在英文不會再自動大寫，要大寫自己按 ⇧，點一下大寫一個字，連點兩下鎖定大寫。
```

### 英文（英國）

```
Fixed a Shift problem on the English keyboard: in an empty text field, ⇧ used to stay on and wouldn't turn off. English no longer capitalises on its own. Tap ⇧ for one capital letter, or double-tap it to lock capitals.
```

App 裡的「新功能」卡片不會跳：程式設定成小修正（1.1 → 1.1.1）不跳卡片，所以 App 這邊不用改。

---

## 二、App 審查資訊的備註（英文）

1.1 的備註原樣留著，最前面加這段：

```
1.1.1 is a bug-fix release. On the English layout, Shift stayed on in an empty text field and could not be turned off. We removed the English auto-capitalisation that caused it; users now tap Shift when they want a capital. Nothing else has changed since 1.1.
```

---

## 三、申請加速審核（Expedited Review）

這次純修 bug，符合 Apple 收加速審核的條件，我建議申請。送審後到 [developer.apple.com/contact/app-store](https://developer.apple.com/contact/app-store/?topic=expedite) 選「Request an expedited app review」，說明欄貼：

```
Version 1.1.1 fixes a keyboard bug in the current release (1.1): in an empty text field, the Shift key on the English layout stays on and cannot be turned off, so users cannot type lowercase English at the start of a message (for example in LINE). This release contains only this fix. We would be grateful for an expedited review.
```
