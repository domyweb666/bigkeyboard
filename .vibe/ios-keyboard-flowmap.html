🤖 給 Claude Code 的讀圖說明 
這份 HTML 包含一個 <script id="flowmap-data" type="application/json"> 區塊。
讀取方式：document.getElementById('flowmap-data').textContent，然後 JSON.parse()。

重要欄位：
- nodes[].trigger_condition：這個狀態的觸發條件
- nodes[].file_responsibilities：每個檔案在此節點的具體職責（本版尚未對應，實作後由 vibe-health-check / vibe-integrate 重跑掛點模式補上）
- nodes[].planned_files：規劃中的檔案（尚未存在，只是計畫）
- file_index：反查表，給你一個檔名，告訴你它出現在哪些節點（本版為空）
- edges[].type：success / failure / retry / conditional，代表分支語意
- nodes[].danger：true 表示此節點黑箱驗不全，動它要特別小心

當你修改一個檔案時，先查 file_index 找到它涉及的所有節點，
再看每個節點的 edges 確認你的修改是否影響到下游分支。
此圖為鎖定基準：任何偏離此圖的架構改動，必須先回 .vibe/架構藍圖.md 改圖並經使用者確認。
