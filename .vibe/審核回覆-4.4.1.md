# 豆鍵 1.0 審核回覆（Guideline 4.4.1 Design - Extensions）

> 2026-11-10 寫。Apple 11/09 用 iPad Air（第 5 代）審 build 67，說「關掉完全取用時鍵盤沒有任何功能」，附的截圖是字典頁那張黃卡。

## 被退的原因

鍵盤程式沒問題：沒開完全取用時，注音打字、候選、聯想、英文、符號、數字鍵盤都照常能用。完全取用只擋學詞、主題、剪貼簿。

問題出在 App 的字。字典頁黃卡原本寫「先開『允許完全取用』……iOS 規定要開這個開關」，審查員看到的就是必開，跟審核備註寫的「Full Access is optional」對不上。

## 這次改了什麼

- 字典頁黃卡：標題改「想讓豆鍵自動學詞？」，內文第一句寫明不開也能打字（`App/FullAccessCard.swift`）
- 使用說明頁：新增「不開完全取用也能用」一段，原本那段標題加上「（選用）」（`App/GuideView.swift`）
- 總測試清單新增 AC 段

鍵盤程式沒動。

---

## 第一步：測新 build

推上 main 之後 GitHub Actions 會編新 build 傳到 TestFlight。裝好後跑完總測試清單 AC 段。AC1～AC5 有一條沒過就先停，把畫面傳給我，不要送審。

## 第二步：錄影（大約 1 分鐘，完全取用關著）

用控制中心的「螢幕錄影」。

1. 打開 設定 > 一般 > 鍵盤 > 鍵盤 > 豆鍵，讓「允許完全取用」是關的這個畫面入鏡，停兩秒
2. 打開備忘錄，新增一則，按住地球鍵選豆鍵
3. 打 ㄋㄧˇㄏㄠˇ，點候選列的「你好」，讓後面跳出的聯想詞入鏡
4. 打 ㄧˋ，按 ⌄ 展開全部候選，點一個字
5. 按「ABC」切英文，打 hello，點候選列的英文預測字
6. 按符號鍵、數字鍵各打一個字
7. 打開豆鍵 App，切到「使用說明」分頁，讓「不開完全取用也能用」那段入鏡
8. 停止錄影，從頭看一次，確認沒有通知或個資入鏡

手邊有 iPad 的話用 iPad 錄更好，審查員是用 iPad 審的。沒有就用 iPhone。

## 第三步：App Store Connect

1. 版本頁的 build 換成新的那一版
2. 「App 審查資訊」的附件換成這支新錄影（舊的那支可以留著一起放）
3. 備註第 3 段「Full Access is optional」那一條不用改，原本就寫對了
4. 到被退的那則訊息按「回覆 App 審查」，貼下面整段，把【build 號】換成新 build 的號碼
5. 送審

```
Hello,

Thank you for the review. The 豆鍵 keyboard works without Full Access. With "Allow Full Access" turned off, users can:

- Type Traditional Chinese with the Zhuyin (Bopomofo) layout
- Pick words from the candidate bar, expand the full candidate list, and pick associated phrases after each word
- Switch to the English, symbol, and number layouts, with English word suggestions

Full Access is used only to save learned words, the selected theme, and clipboard items to the App Group shared with the companion app. The keyboard has no networking code.

The card at the top of the 字典 (Dictionary) tab, shown in your screenshot, read as if Full Access were required. In build 【build 號】 we changed it: it now says the keyboard can be used without Full Access, and that Full Access only adds word learning, themes, and the clipboard. The 使用說明 (Guide) tab also has a new section listing what works without Full Access.

To try it with Full Access off:
1. Settings > General > Keyboard > Keyboards > Add New Keyboard > 豆鍵. Leave "Allow Full Access" off.
2. Open Notes and tap the globe key to switch to 豆鍵.
3. Tap ㄋ ㄧ ˇ ㄏ ㄠ ˇ, then tap 你好 in the candidate bar.

A new screen recording made with Full Access turned off is attached in App Review Information.

Thank you.
```

## 還沒驗證的

- 「完全取用關著照常打字」從來沒在真機打勾過（舊的 X7、新的 AC 段），這次一定要測
- 豆鍵只做 iPhone 版，鍵盤在 iPad 上沒跑過。審查員用 iPad，如果 iPad 上鍵盤畫不出來或按不動，回覆寫得再清楚也會再被退。可以用 limrun 開 iPad 模擬器測（以分鐘計費，測完要關）
