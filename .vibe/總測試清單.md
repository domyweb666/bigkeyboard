## A. 注音鍵面
- [ ] A1 四排注音照三星排：ㄅㄉˇˋㄓˊ˙ㄚㄞㄢㄦ／ㄆㄊㄍㄐㄔㄗㄧㄛㄟㄣ／ㄇㄋㄎㄑㄕㄘㄨㄜㄠㄤ／ㄈㄌㄏㄒㄖㄙㄩㄝㄡㄥ⌫；最下排 符 🌐 ， 空白 。 123 ↵
- [ ] A2 鍵帽文字沒有底線
- [ ] A3 每顆注音鍵右上角有小灰字（第一排 1–0、第二排 + × ÷ = / _ < > [ ]、第三排 ! @ # ¥ % & * ( )、第四排 - ' " : ; , ?）
- [ ] A4 按下任一注音鍵，鍵上方跳出放大的字，放開消失
- [ ] A5 打 ㄋㄧˇ → 工具列左側灰字「ㄋㄧˇ」，右側候選第一個「你」
- [ ] A6 打 ㄅㄨㄧㄠˋ → 整串顯示、候選第一個「不要」；點它或按空白 → 輸入框「不要」
- [ ] A7 不打聲調 ㄅㄨㄧㄠ → 一樣出「不要」
- [ ] A8 打 ㄋㄧˇㄏㄠˇ → 候選第一個「你好」
- [ ] A9 打 ㄨㄛˇㄇㄣ → 「我們」
- [ ] A10 打 ㄓ 再按 ㄅ → 顯示「ㄓㄅ」（自動斷音，跟 iPhone 一樣）
- [ ] A11 組字中按 ⌫ → 一次退一個注音符號；跨音節也行（ㄅㄨㄧㄠˋ 按一下變 ㄅㄨㄧㄠ）；注音空了再按 → 刪輸入框的字
- [ ] A12 組字中按「，」或「。」→ 先送出第一個候選、再送全形標點
- [ ] A13 組字中按 ↵ → 先送出第一個候選、再換行
- [ ] A14 長按 ㄅ（≥ 0.4 秒）→ 輸入框出現「1」，沒有送 ㄅ
- [ ] A15 組字中切走鍵盤（點別處）→ 組到一半的字被送出，不會消失
