## 備註
- 沒有 Mac，所以每次驗片都要等雲端編譯＋TestFlight 處理（約 10–20 分鐘）。片 7（外觀、泡泡）這種要反覆微調的片，一次改動要集中多個調整再推，不然會等到放棄。
- 片 1 之前，使用者要自己完成：加入 Apple Developer Program（年費 99 美金，自己付）、在 App Store Connect 建一把 API 金鑰、把金鑰放進 GitHub 的 Secrets。AI 不碰付款與金鑰內容，只給步驟。
- 片 4 的「我驗不了」是整本詞庫的品質——只能驗自己常打的字。這片做完要標給 vibe-health-check。
- 片 4 引擎進來前先停下來確認授權（MIT／BSD 直接用；GPL 類要問）。
- 片 5 之後可以考慮平行：片 8／10／11 三張鍵面彼此獨立（由 vibe-parallel-control 精判）。
