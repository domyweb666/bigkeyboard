# 標準清單（本次任務：片 1 walking skeleton）

## ✅ 必須做到（可操作測試句）
- [ ] 我在 Xcode 按 Run（選我的 iPhone 當目標），應該看到容器 app 裝到手機上並打開，畫面上只有一行字「請到 設定 → 一般 → 鍵盤 → 鍵盤 → 新增鍵盤 加入本鍵盤」。
- [ ] 我到 iPhone 設定 → 一般 → 鍵盤 → 鍵盤 → 新增鍵盤，應該在第三方鍵盤清單裡看到這個鍵盤（名稱暫定「三星風鍵盤」）。
- [ ] 我加入後，到茄記點一個輸入框，長按地球鍵切到這個鍵盤，應該看到整塊鍵盤區域變成灰底（顏色先不講究），上面只有一顆白色的「ㄅ」鍵。
- [ ] 我按那顆「ㄅ」鍵，應該看到輸入框游標處出現「ㄅ」；連按三下出現「ㄅㄅㄅ」。
- [ ] 我切回原生鍵盤再切回來，應該看到鍵盤還在、還是那顆「ㄅ」鍵，沒有閃退。
- [ ] 我到一個密碼欄位（例如 Safari 任一登入頁的密碼框），應該看到系統自動換回原生鍵盤，不會是我的鍵盤、也不會閃退。
- [ ] 我故意連續快速按「ㄅ」鍵 20 下，應該看到 20 個ㄅ，鍵盤沒有卡死或消失。

## 🎯 每條的意圖
- 「容器 app 裝到手機並打開」是為了確認 Xcode 專案、簽章、裝置信任這整條路通了——第一次最容易卡在這裡。
- 「在設定裡看得到鍵盤」是為了確認 extension 的 Info.plist 寫對、iOS 認得它是鍵盤。
- 「切過去看到灰底＋一顆ㄅ鍵」是為了確認 extension 真的跑起來、畫面是我們畫的不是系統預設的。
- 「按了出現ㄅ」是為了確認「鍵 → 送字進輸入框」這條最核心的路通了；之後所有鍵都走同一條路。
- 「切走再切回不閃退」是為了確認 extension 的生命週期沒問題，不是只能用一次。
- 「密碼欄自動回原生」是為了確認定稿裡「密碼欄不處理」這條系統行為真的如預期。
- 「連按 20 下不卡」是為了確認按鍵處理沒有被某種延遲或堆積拖住，之後打字才不會有延遲。
