## 1. 最可能出問題的地方（我沒辦法在這台驗）

- [ ] 系統原本的分頁列有藏起來，底部只有一條白色膠囊分頁列（iOS 26 上最要看這個）
- [ ] 五個分頁都切得過去：字典、剪貼簿、主題、設定、說明
- [ ] 在字典或剪貼簿點搜尋框，鍵盤叫出來時，膠囊分頁列留在原位、被鍵盤蓋住，沒有跳到鍵盤上面
- [ ] 每一頁捲到最底，最後一筆沒有被分頁列蓋住
- [ ] 字典頁的詞是一張白卡，左右邊距跟上面的搜尋框對齊；左滑刪除還在
- [ ] 管理標籤那頁同上：白卡、左滑刪除、點一下改名

## 2. 字典

- [ ] 沒開完全取用：看到淡綠色提醒卡，有「選用」小膠囊、三步、綠色「前往設定」
- [ ] 鍵盤寫過資料：看到「自動學習中・幾分鐘前更新」，右邊有「幾個詞」
- [ ] 篩選三格（所有、自動、手動）切得動，選中的是白底
- [ ] 搜尋打字後右邊有 ✕ 可以清掉；找不到時顯示「找不到符合的」
- [ ] 右下角綠色＋開加詞視窗
- [ ] 加詞：打「長輩圖」，下面出現三顆讀音卡；「長」的讀音在綠色膠囊裡、有箭頭，點了可以換
- [ ] 加詞：打一個詞庫沒有的字，那顆變紅框「查不到」，下面紅字說不能加，「加入」是灰的

## 3. 剪貼簿

- [ ] 右上角白色圓鈕（標籤圖示）開管理標籤
- [ ] 篩選膠囊可以左右滑到螢幕邊；選中的是綠底白字
- [ ] 卡片白底大圓角；固定的右上角綠色圖釘；有標籤的下面一顆淡綠膠囊
- [ ] 點卡片開編輯：文字框打字時綠框；固定開關是綠的；標籤是一顆顆膠囊，多了會換行，點了打勾
- [ ] 「刪除這筆」是淡紅底紅字，按了會再問一次
- [ ] 管理標籤：每列右邊有「幾筆」

## 4. 主題（這頁的流程改了）

- [ ] 上面是大預覽：整張注音鍵盤，第二、三排左右各縮半顆，底排撐滿
- [ ] 點下面任何一張主題卡，只換上面的大預覽，不會跳付款視窗
- [ ] 大預覽的字體跟著主題換（豆漿明體、紅豆楷書、糖豆粗體）
- [ ] 擁有、沒在用的主題：預覽下面是灰色「換成這款」，按了右邊出現「使用中」
- [ ] 沒買的主題：預覽下面是綠色「買下這款　NT$60」，按了才跳 Apple 付款視窗
- [ ] 價格還在載：轉圈；載不到：「價格沒載入，點一下重試」
- [ ] 同一排兩張主題卡一樣高
- [ ] 最下面「前往設定」「回復購買」都還在、都能按

## 5. 設定、說明

- [ ] 設定頁：空白鍵開關是綠的，下面說明文字會跟著開關換
- [ ] 說明頁：最上面「開始用豆鍵」三步，第三步是空心圈加「選用」
- [ ] 說明頁：「到 App Store 寫評論」（有設 App Store ID 才會出現）

## 6. 鍵盤

- [ ] 鍵位、鍵寬、鍵帽配色、候選列跟改版前一模一樣（這次沒動）
- [ ] 剪貼簿面板：選中的篩選是綠底白字，其他是白色膠囊
- [ ] 卡片上的標籤是綠色粗體，圖釘是綠的
- [ ] 按住卡片：選單變成一張寬卡，上面一行是那筆的開頭，兩顆並排大按鈕「固定」「刪除」（刪除淡紅）
- [ ] 選單裡的標籤是一排膠囊，多了可以左右滑；勾一個之後那排不會捲回開頭
- [ ] 選單外面點一下會關；「取消」也會關
- [ ] 換成別的鍵盤主題（紅豆、糖豆）再看一次剪貼簿面板，綠色跟主題色搭不搭
- [ ] 小螢幕（iPhone SE）選單放不下時可以上下捲

## 7. 整體

- [ ] 深色模式每一頁看一次（深色的綠是算過對比的，還沒在真機上看過）
- [ ] 系統字級調到最大，分頁列的字沒有破版
- [ ] 打字手感：這次鍵盤只動了剪貼簿面板和選單，注音打字應該沒有差別

## 這次沒做的

- 候選全部展開時，畫布上畫的「ㄉㄡˋ・幾個候選」那一行沒做。候選列不知道正在組的注音是什麼，要另外接
- 編輯一筆裡的「管理標籤」連結沒做，還是照舊回剪貼簿頁按右上角
- 鍵盤選單的標籤是一排左右滑，不是畫布上的換行（鍵盤高度有限，換行會擠掉取消鍵）
- 畫布還是四個分頁、沒有設定頁
